# 福利中心布局

## 设计范围

仅调整福利中心与抽奖盘、中奖动态组件，不改变账户请求、签到、抽奖和兑换逻辑，不修改其他页面的公共导航。

- 采用系统字体、浅灰背景、深色文字、细分隔线和蓝色操作按钮。
- 账户概览、抽奖与签到、积分兑换形成三个明确层级，移除包裹整页的白色卡片。
- 中奖记录和实时播报使用分段视图，保留分页、刷新、错误提示与播报暂停功能。动态区域固定高度并允许内部滚动，避免切换时撑高布局。
- 抽奖盘保留已有奖品图片，边框改为浅灰；画布与锁定遮罩使用相同的 8px 内边距、6px 间距。
- 小屏幕下切换为单列布局，积分兑换商品改为横向紧凑排列。

## 验证

- `npx tsc --noEmit` 通过。
- 三个改动 TSX 文件的 Next ESLint 检查无错误，抽奖盘保留原有原生 `img` 优化建议警告。
- 浏览器检查桌面和 390px 手机宽度截图；手机文档宽度未超过视口，抽奖画布和锁定奖品显示正常。
- 未在真实账户上执行抽奖、签到或积分兑换。本次不涉及业务规则改动。

页面地址：`http://localhost:3003/#/market`。
